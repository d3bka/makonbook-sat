MakonBook Structured PDF v2

Convert the original test with an external AI first. V2.1 keeps tables, graphs, and diagrams as deterministic visual regions, removes PDF-only line wrapping, and preserves underlines, blanks, emphasis, and KaTeX-ready math with explicit markers.

Create one EBRW PDF and/or one Math PDF. Question counts are read from the file, so Placement and custom tests can contain fewer or more questions than a standard SAT. The downloadable conversion prompt is the authoritative text/math contract. Ordinary PDF line wraps must not be encoded as semantic line breaks.
